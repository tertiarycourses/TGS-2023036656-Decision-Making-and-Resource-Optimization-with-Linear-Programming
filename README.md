## About the course

This practical course develops a structured workflow for allocating limited resources, comparing choices under uncertainty, and evaluating competing plans against multiple criteria. Learners translate business problems into mathematical models, solve and interpret them in Excel, and turn the results into actionable recommendations and KPIs.

## Learning outcomes

By the end of the course, learners should be able to:

1. Develop a resource-management strategy and plan using Linear Programming.
2. Develop a resource-allocation plan and track resource usage using Decision Analysis.
3. Evaluate resource-management performance using Multi-Criteria Decision Analysis.

## Topics covered

- Optimisation and Linear Programming models for resource management
- Formulating decision variables, objective functions, and constraints
- Solving LP models with Microsoft Excel Solver
- Sensitivity analysis, shadow prices, and scenario testing
- Expected Value, EVwPI, EVPI, risk, and Expected Utility
- Weighted scoring boards for multi-criteria decisions
- Analytic Hierarchy Process priorities and consistency checks
- Integrated resource-allocation evaluation and KPI design
